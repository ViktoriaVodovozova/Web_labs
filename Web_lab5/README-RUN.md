# Лабораторная работа №5 — Next.js + Spring Boot

## Запуск

1. Установите Docker Desktop и запустите его.
2. Откройте терминал в каталоге `Web_lab5`.
3. Выполните `docker compose up --build`.
4. Откройте http://localhost:3000.

Остановить: `docker compose down`.

По умолчанию backend доступен только внутри сети Docker (`http://backend:8000`).
Если нужно открыть Swagger в браузере, временно добавьте в сервис `backend` в `docker-compose.yml`:

```yaml
ports:
  - "8000:8000"
```

## Учётные записи

Администратор создаётся backend при запуске. Имя пользователя и пароль смотрите в настройках backend; значение `ADMIN_PASSWORD` в `docker-compose.yml` по умолчанию `Admin12345` (только для локальной разработки).
Обычного пользователя можно зарегистрировать на странице `/register`.

## Что сделано

- Next.js App Router: SSR списка и деталей, маршруты `/students/[id]`, страницы 404 и ошибок;
- JWT: вход, регистрация, выход, HTTP-only cookies;
- серверные действия: создание, изменение и удаление студентов;
- поиск, фильтры, сортировка и пагинация;
- роли проверяет Java backend, UI скрывает недоступные действия;
- Docker Compose для двух сервисов.

Автоматическое обновление access-токена не добавлено: после истечения срока действия требуется повторный вход.

## Проверка

В среде подготовки архива не было доступа к npm registry и Docker. Поэтому сборка `next build` и запуск контейнеров **не проверены**. Если сборка упадёт, пришлите первые строки ошибки `npm run build`.

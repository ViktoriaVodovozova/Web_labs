# История действий пользователей

На `/students` администратор видит сворачиваемый блок «История действий пользователей» под списком. По умолчанию закрыт.

События CREATE, UPDATE, DELETE, RESTORE фиксируются в таблице `audit_events` базы H2 после успешной операции через Spring Boot. Хранятся имя пользователя, действие, ID и ФИО студента, дата и время. Показываются последние 30 записей (новые сверху).

`GET /api/audit` доступен только ADMIN, JWT обязателен. История сохраняется в Docker volume `students-data` между перезапусками.

Запуск: `docker compose up -d --build`; открывать `http://localhost:3000`.

Ограничения: не журналируются логины и чтения, только изменения студентов; уже совершённые действия до установки не появятся; отображение времени — МСК. Для промышленного аудита желательно обеспечить атомарную запись события и бизнес-операции в одной транзакции.

# Изменения относительно Web_lab6

- Перенесён RateLimitFilter из лабораторной №5 с Bucket4j + Caffeine и подключён к Spring Security. Лимиты по IP: login — 5/мин, register — 3/мин, refresh — 10/мин, `/api/requests` — 100/мин, прочие — 60/мин. Превышение: HTTP 429 и Retry-After.
- Добавлено поле `@Version` для JPA optimistic locking и обработка конфликтов HTTP 409. Текущая блокировка `PESSIMISTIC_WRITE` из лабораторной №6 сохранена.
- PUT и PATCH требуют `If-Match` из ETag, возвращаемого QUERY `/api/requests/{id}`. Нет заголовка — 428; устарел — 412. Проверка выполняется после блокировки записи во время транзакции.
- Форма редактирования Next.js передаёт ETag; при конфликте показывает предупреждение и повторно загружает актуальные данные.
- Реализация WebSocket, Node.js, оповещения и базовая структура лабораторной №6 сохранены.

Важно: локальные token buckets рассчитаны на **один экземпляр** Java backend. Для нескольких реплик нужен общий storage, например Redis.

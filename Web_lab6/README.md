# Лабораторная №6. WebSocket

## Запуск

Создайте файл `.env` рядом с `docker-compose.yml`. Задайте в нём `ADMIN_PASSWORD`, `JWT_SECRET` и `SERVICE_KEY`. Для каждого ключа сгенерируйте отдельное значение командой `openssl rand -hex 32`.

В каталоге проекта выполните `docker compose up --build` и откройте [http://localhost:8080](http://localhost:8080).
Для локальной демонстрации войдите как `admin` с паролем `ADMIN_PASSWORD` из `.env`. Обычного пользователя можно зарегистрировать через интерфейс.

В меню ADMIN откройте **Журнал и CSV**. Для проверки WebSocket откройте список студентов в двух вкладках и создайте, измените или удалите запись. Во второй вкладке появится уведомление. Журнал хранится в томе `rt-data` и сохраняется при обычном перезапуске контейнера.

## CSV

Используется UTF-8 и запятая. Экспорт можно взять за шаблон.

```csv
id,fullName,group,isuId,dormitory,room,moveInDate,isForeigner,notes
,Иван Иванов,P3101,012345,1,101,2024-09-01,false,"Заметка, с запятой"
```

Для новой записи оставьте `id` пустым. При импорте существующие записи определяются по `id` или `isuId`. Можно пропустить существующие записи, обновить их или показать ошибку по каждой такой строке. Для обновления Java проверяет `If-Match` под блокировкой записи. Ошибки отдельных строк видны в результате задания, а успешно обработанные строки сохраняются.

## Сервисы

- Java выполняет JWT-аутентификацию, проверяет роли и работает с H2. После фиксации транзакции Java отправляет событие в Node.js.
- Node.js на встроенных модулях хранит аудит, обрабатывает CSV потоками и рассылает события ADMIN через WebSocket. JWT остаётся в HttpOnly-cookie. Для Upgrade браузер получает одноразовый билет.
- Nginx передаёт `/rt/` в Node.js, маршрутизирует API и SSR и блокирует внешний доступ к служебному обработчику событий.

Из каталога `node-realtime` выполните `npm test` для проверки CSV, WebSocket и контрактов с имитацией Java.

Java отправляет события после коммита с ограниченным тайм-аутом. Если Node.js недоступен, изменение останется в H2, а событие не будет доставлено.
